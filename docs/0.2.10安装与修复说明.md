# 本地翻译器 0.2.10 安装与修复说明

当前版本为0.2.10，语音软件0.2.10-r5；具体候选build及路径见发行指标。此版本为 macOS 26 及更新系统、Apple Silicon 的个人自用整合候选。最终版本/build 和通过范围以同目录开发记录及指标为准。使用本机临时签名，延续个人自用范围，未新增 Developer ID 公证。

## 安装 App

优先打开 DMG，将“本地翻译器.app”拖到“应用程序”或自己选择的独立目录，推出映像后打开。ZIP 是相同 App 的备用格式。请保留旧版 App 与全部任务。遇到系统安全或文件权限提示，按系统提示处理；不要删除安全标记或重置其他应用权限。

## 分项准备

打开“本机资源”。文字服务和语音运行环境分开检测；已有兼容 Ollama 0.35.0 会复用。原服务、原模型和全局设置保留。已安装而未运行时，可主动启动。端口占用或版本不兼容时停止准备并显示原因，不替换原安装。未安装时可主动准备官方固定引擎，安装后再次主动启动。官方入口为 https://github.com/ollama/ollama/releases/download/v0.35.0/Ollama-darwin.zip，SHA-256 为 3458972dfca5b3f8a4297a8d7ff503da3e180ec9452ba8de82c69c5ba3aacdd9。

语音使用固定、独立的 Python/库/识别代码包，按完整可信清单校验、启动自检后激活。个人自用语音包可点击“导入已校验运行包”选择本轮 ZIP。该包尚未公开托管，联网入口为空；公开下载验收尚未完成。PyAV 自带解码库的对应源码及编解码库分发条件仍待补齐，源码 Git 授权不等于公开二进制授权。

首次完整导入自检最多等待 120 秒，取消仍可停止；这一限时独立于原 worker 的真实启动确认及 30 秒超时保护。新路径及无缓存时实际准备可能较慢。

下载显示进度；取消后清理本次临时文件，重试会重新下载，最多两次自动网络尝试。安装失败保留原可用环境。独立 Python 以隔离及显式禁止写字节码的模式启动；自检前后两次核对完整软件文件，防止自检生成文件后仍误报已安装。任务运行时不切环境，双窗口共享安装锁；异常退出留下的已确认安装临时目录在下次准备时清理。修复只导入/下载同一固定包并重新校验，不修改全局 Python/Conda/Homebrew、不删模型或任务、不回退数据库。

## 外部资源

选择外部 models 文件夹。流式主功能需要 whisper-mps-experiment/large-v3-turbo（完整 weights.safetensors、config.json）以及 speech-runtime-data-v1（校验清单中的分词/梅尔编码/VAD 数据）。本轮已有匹配资源直接复用，无需下载或更换模型。CoreML 和对应 tokenizer 仅用于旧原生对照入口，不作为流式前提。

翻译保持 hy-mt2:7b-q8 与已验证保真 v2 配置，8192/4096、keep_alive 5m 不变，1.8B 仅手动或旧任务。不会自动拉取模型、换 tag、改变语音精度或减小上下文。共享 Ollama 不主动卸载模型或停止服务；本应用启动的服务采用自然驻留，在安全退出后停止自己的进程。

## 保存、恢复和内存

文字/文档保存在 ~/Library/Application Support/LocalTranslator/TextDocuments；录音保存在 Recordings；运行环境保存在 Environments，与模型及任务分离。打开任务只读取，主动继续只处理未完成部分；成功译文、原文修订与旧 recipe 保持。旧录音物理路径消失时，只有内容身份及 digest 一致才允许重新定位。无法确认兼容时保留可读/导出内容，不覆盖旧 runtime.json。

任务结束或安全取消后释放语音引用和框架缓存，等待尾部处理与保存，不提前杀 worker。首批稳定空闲占用下降，但进程高水位没有下降；最终包实测单列于指标，不能把缓存调用或 RSS 求和当整机内存收益。

麦克风、休眠、外置设备等实机操作由用户主动开始。新启动路径的真人麦克风与休眠复验尚待用户操作；外置拔插沿用 0.2.9 已接受未验证限制。识别与翻译仍有错误，D02 勘误及 D20/H09、部分否定误译等已接受质量限制保持，完成处理不代表内容准确。


## 本轮文件与校验

主安装文件为发行目录内的 `本地翻译器-0.2.10.dmg`，备用 `本地翻译器-M0.zip` 为同一App。语音软件为 `dist/Runtime-0.2.10-r5/speech-runtime-0.2.10-r5-macos-arm64.zip`，SHA-256为72bb28972b8262b68184d28f0b0341cef3cd26cf697240b7510b387bb1eeb4eb。DMG/ZIP和软件包实际大小/hash、真实官方Ollama入口以及未发布语音入口的原因见[资产清单](0.2.10二进制分发待办与资产清单.md)。这些本地二进制没有上传到Git。

当前候选已处理环境校验缓冲滞留、旧任务路径不可读时的内容一致重新定位，以及校对只加载自身MLX资产适配。旧路径不可读不等于可以忽略身份：仍需要已保存digest且重算一致，否则拒绝继续，保持可读/导出内容。安装包内的简短说明按打包时通用操作保留，完整更新状态以这份说明及指标为准。

旧任务搬动后的回放使用当前任务目录内的audio.wav；已有完整音频校验值时先核对内容，错配拒绝回放，快照/数据库/原绝对路径证据保持。没有完整hash的旧或处理中快照只允许读取本地归档，不因此允许继续识别或绕过恢复检查点。
