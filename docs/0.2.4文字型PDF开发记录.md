## 实际实现

- `DocumentTextReader` actor 独占提取 PDFKit 对象，后台读取最多 256 MB 的文件，固定内容字节和 SHA-256。PDF 预览在主线程从相同不可变字节创建独立对象，不与提取对象跨线程共享，也不会因源路径被替换而显示另一份文件。
- PDF 先显示真实总页数，再选择全部页或连续物理页范围；每轮最多 200 页，支持 201–220 等大起始页码，越界、倒序或超量明确拒绝。新路径仅调用文字层，不进入旧 auto/OCR 回退。
- 每个选定页均有独立记录：待提取、已提取文字、未提取到文字、读取失败、停止未处理。无文字不推定为空白；混合页图片文字没有覆盖保证。
- 保留 PDFKit 原始页文字，按同页原始顺序将多行组成有界阅读片段；沿用 `LongTextSplitter` 的保守边界，不做几何段落重建、不删除页眉页脚、真实重复、标点或数字，不猜测断词，不跨页合句。每片段保留页码、片段序号及页内 UTF-8 半开范围；TXT 使用全文 UTF-8 范围，去除 UTF-8 BOM，不伪造 PDF 页码。
- 已有 `TextTranslationController` 增加预分段入口，复用原串行调度、完成检查、容量、失败和取消规则。文档层保留独立来源与覆盖信息，固定模型、方向、范围和提取快照。UUID 和取消状态隔离旧回调。
- 切页、阅读、滚动及 PDF 定位不启动新任务；每段完成增量显示，翻译结果不会主动切回第一页。模型、方向和范围在运行时禁用。停止取消当前请求、不再调度后续片段、不停止共用 Ollama。
- 复制仅包含完成译文。双语 TXT 包含文件名、SHA、总页数、范围、模型、方向、覆盖统计、每页完整原始提取文字，以及对应段状态、范围、译文和核对提示；原文按页只写一次。零译文、失败、提取停止和翻译停止都可导出已有快照。
- 文件读取、提取、分段、导出拼接和写盘异步执行。提取前及每次翻译请求前后检查源文件大小/修改时间；变化或不可读时保留原快照并提示。测试发现 Foundation URL 会缓存资源属性，已通过使用新 URL 并清除缓存修正。该检查不是持续文件系统监控，也不能检测人为保留相同大小及修改时间的内容替换；固定字节快照仍不受影响。
- 旧选段 UI 和操作入口均按 2,048 UTF-8 字节预算保护；超量提示复制到文字页自动分段。退出提示明确文档结果不会恢复，返回应用保留窗口和结果；录音的停止等待行为保持原有实现。

## 仍有的限制

PDFKit 的可提取文字及顺序不等于 PDF 全部可见内容。本轮不识别图片中文字，不修复复杂双栏、表格、公式、连字排版或跨页语义。片段按保守容量组织，序号不承诺等同于作者的自然段。页眉页脚和真实重复保留，因此模型可能将它们一并翻译。

不提供恢复、历史任务、续跑、重试、术语库、HTML/原版排版回写；停止后重新开始为新一轮。关闭后数据不恢复，长期保存依赖复制/导出。7B、完整断网、多机、200 页真实模型长测、复杂混合文档及新的长时语音均未验证。自用包要求 macOS 26 或以上，使用本机临时签名，未做 Developer ID 公证，仍依赖本机模型及原语音运行环境。
