## 四项已实现能力

1. **显式 OCR 范围提取。** 在现有「文档与图片 → PDF / TXT 整篇」中主动选择整页 OCR，支持全部页或连续物理页范围，每轮最多 200 页、文件最多 256 MB。默认文字层不触发 OCR，TXT 不显示 OCR 选项；显式 OCR 用作该页的替代来源，不自动混入文字层。
2. **逐页核对与翻译前校正。** 同页查看原 PDF、识别文字、来源、置信度及问题提示。保存/取消编辑明确，草稿切页保留，未保存时阻止翻译和关键设置切换；保存后后台重建完整分段。原始观察项不随校正覆盖；支持人工清空或补入，并明确来源。人工核对由用户设置，修改后重置，不因识别或翻译完成自动标记。
3. **接入整篇翻译和双语阅读。** 复用原串行控制器、预算和模型引擎，识别与翻译分阶段、分开显示进度。开始翻译后固定来源修订；停止保留完成译文，继续按页阅读和原页定位。“重新核对并开始新一轮”先确认清除当前译文，再保留原始 OCR 与校正文重新核对，不提供续跑。
4. **来源完整的双语 TXT。** 点击时捕获一致快照，保留所选全部页、原始 OCR、有效原文及修订、人工编辑/核对、问题、完成译文和失败/中断/待处理状态。无文字、失败或停止未处理页均不消失。复制只取当前修订完整完成的译文；导出不含未保存草稿。退出提示明确识别、校正、核对和译文不自动恢复。

## 资源、来源与取消实现

`DocumentTextReader` actor 串行持有提取用 PDFKit 对象，UI 从独立不可变字节快照创建预览。渲染采用 cropBox 与 mediaBox 的可见交集，应用 PDF rotation；在分配前限制最长边 3,000 像素、总像素 900 万、缩放最多 3。每页 autoreleasepool 释放位图及临时 Vision 对象，不保留整书高清位图。文件读取、渲染、Vision、分段及导出拼接/写盘在后台执行。

原始 OCR 证据包含观察项 ID、顺序、文字、置信度、归一化坐标、坐标系、像素大小、rotation、cropBox 和语言。有效原文、人工编辑、核对状态及修订 UUID 单独保存，翻译片段的 UTF-8 范围关联有效修订；人工增删不伪造逐字 PDF 坐标，也不计作 OCR 覆盖成功。

`OCRCancellation` 使用独立锁保护请求句柄，直接调用 `VNRequest.cancel()`，没有把取消消息排在同步 `perform` 阻塞的 actor 后面。停止后不接受当前页部分结果、不启动下一页；OCR、分段和翻译三条路径均检查取消和 UUID，隔离迟到回调。

实测中修正了三项问题：

- CGPDF drawing transform 不会自动放大小页面，旧实现把原页居中在更大的位图中，没有提高文字像素。现在先显式缩放 CGContext，再用 PDF 点坐标映射 cropBox/rotation，并加入放大、裁切和旋转的像素角点回归。
- 同一中文位图的 Vision 结果受语言优先级影响。现在按用户明确选择的翻译方向固定英中 `[en-US, zh-Hans]`、中英 `[zh-Hans, en-US]`，不做自动语言检测。测试生成器也改为嵌入本机 Arial Unicode，避免未嵌入 CID 字体被 Poppler 渲染为空。
- 原 `OllamaEngine.cancelRequests()` 立即使 URLSession 失效，会与后续 URLSessionTask 创建竞争并触发不可捕获的 NSException。现在标记取消、拒绝新请求并取消已有 tasks，deinit 才使 session 失效；不停止用户共用 Ollama。修正后重新完成真实停止及最终包操作。

## 已知限制与未完成验收

清晰合成样本的逐字 OCR 一致不能推广为任意扫描件的准确率或完整性。RFC 排列顺序及低置信度项仍须核对，大页实测存在漏字。Vision 置信度只是识别器提示，不是完整性证明。

模型正常结束也不证明翻译忠实：最终包第 1、2、4 页各有两次重复句，译文只保留一次；`extension` 被译为“扩建／扩展”，可能不合语境；中文→英文结果出现 `Please keep any重复 content intact.`。这些问题已记录，没有通过删除原文重复来掩盖，也没有将模型质量列为全面验收通过。

以下未完成或继续暂缓：

- 真实扫描噪声、复杂双栏、表格／公式、手写、自动纠偏、语言自动检测及混合区域自动合并。
- 7B、完整断网、多机、200 页真实模型推理和长期内存稳定性验收。
- Office 整篇、原排版回写、HTML/PDF 双语排版导出、术语与资料库。
- 文字／文档任务持久化、历史、恢复、续跑、单段及自动重试；退出后需依靠主动导出保存。
- 新的语音专项和真实课堂长时验收，本轮未扩展。

包要求 macOS 26 或更新、当前 Apple Silicon Mac 的本机模型和现有语音运行环境，使用本机临时签名，未做 Developer ID 公证，也不是包含模型的独立安装发行版。
