## 1. 最终实现和结论边界

| 环节 | 证据与最终修改 | 结论 |
| --- | --- | --- |
| 已确认文字提交 | 原后端仅按上一提交终点加 50 ms 过滤词，重复字符串保护还会丢弃批次并清空未确认音频。取消这种删词/清空，保留文字、原事件、音频并标记核对位置 | 确定性内容丢失已修复并经故障注入验证；不代表模型所有重复已解决 |
| 解码停止符 | 已有确认前缀的续写仍屏蔽 EOT，会强迫生成多余词。现允许正常停止；初始识别的 blank 保护保留 | 原波形样本中插入退化得到修复；不采用仅取消旧保护的中间版本 |
| 窗口与确认前缀 | 输入音频块数与推理批次数不对应，旧实现每删一块音频就删一批确认前缀。最终记录确认批次的实际输入终点，按媒体推进整批转入历史上下文 | 自动测试覆盖空输出、合并输入、不同批次和批次原子性；不使用有偏差的词时间淘汰内部前缀 |
| 非默认尾词分支 | `_split_tokens` 内部扣除未确认尾词，对外却包含它。现只输出确认前缀，EOF 交付尾词一次 | 受控实际方法测试通过。默认 `always_fire=True`，不能把这项称为默认路径历史故障根因 |
| VAD 起始 | 第二个 start 覆盖未关闭的首个 start。现保留最早起点，合并 start/end 事件均处理 | 故障注入通过；历史长测 `late_events=0`，不是已证实的历史漏词原因 |
| 静音与暂停时钟 | 长静音重置曾取最后一个词估计终点，现使用实际静音样本起点；处理器 origin 固定，恢复只加一次；拒绝旧处理器写回 | 真实媒体静音保留，墙钟暂停不加入 WAV；自动和模拟 PCM 验证 |
| 已确认停顿分段 | 上游完成静音处理后通知运行层；过滤后的真实静音≥0.5秒时保存无标点确认尾部，标记“停顿暂分” | 不伪造 EOF/任务完成；阈值不等于说话人全部停顿，因为 VAD 有前后保留量 |
| 空识别与异常估计 | 记录送入样本、VAD分类、调用与确认数量；10秒活跃音频没有确认文字时提示回放。诊断历史有界 | 不猜测补词。模型有声音但无输出的风险可见，仍可能漏报短缺口 |
| 时间与导出 | 保存局部估计、样本原点、原始全局估计；检查非有限/负值/逆序/越界/零时长/明显回退。标点不扩展语音范围。页面、TXT、SRT、VTT共用有效时间 | 不删文字、不累计顺延。边界合法与声学对齐分别验收；后者未全通过 |

模型仍为现有 large-v3-turbo，流式使用 MLX 编码＋MPS FP32 解码、0.5秒合并、128 token 上下文和原 VAD 配置；中文使用本机 HY-MT2。不下载模型，不添加强制对齐模型，不注入参考稿提示词。

## 5. 独立声音锚点和时间目标

在推理前固定20句锚点：系统已有 Daniel 音色逐句生成原创短句，按各句外沿 PCM 幅值≥80/32768 取起止，标注低能音素±80ms不确定范围。句间加入2秒真实静音，开头/暂停边界6秒；总94.3766875秒。暂停/继续发生在同一媒体样本809629，事件记录95秒墙钟间隔，WAV不插入假静音。

这属于**独立合成波形参考，不是人工听辨真人语音标注**。文本用全局词序列对齐到完整已保存字幕；首尾词不匹配的句子列出，不用模型时间充当真值。
