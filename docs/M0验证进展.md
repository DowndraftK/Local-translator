# M0 验证进展

日期：2026-09-14  
状态：本机 HY-MT2 / Whisper 集成测试已跑通，存在条件误译与语音切句问题；M0 尚未完成。

## 原生交互测试包

已新增 SwiftUI 原生窗口并生成 `.app` 与 ZIP，入口见根目录 [README](../README.md)。界面复用现有工作进程，提供文字翻译、文档/图片提取及选段翻译、英语录音文件转写/翻译、来源和时间轴显示、双语 TXT 导出、本机资源检查及 Ollama 启动。

已在真实应用窗口中执行示例文字翻译、合成 Word 文件提取及选段翻译、26.1 秒合成录音双语处理和保存。语音本轮处理约 3.99 秒，首次加载另约 105.02 秒；这仍是合成材料测试。Release 构建及临时签名校验通过，原有 11 项基础检查通过。交互验收详见 [M0界面与打包验收](M0界面与打包验收.md)。

当前没有麦克风录音或实时字幕实现。WhisperKit 的 `AudioStreamTranscriber` 提供实时转写、VAD 入口和已确认/待确认片段，可作为下一步基础；项目还须实现音频持久化、有界缓冲、整句稳定提交、中文翻译队列、尾句处理和中断/恢复。生成 `.app` 不改变这些剩余边界。

## 最新进展：模型联调

已补齐两套 Whisper 分词器并校验资源，接入用户下载的 `hy-mt2:1.8b-q8`、`hy-mt2:7b-q8`。两套文字模型均完成双向翻译，两套 Whisper 均能加载和转写；turbo + 1.8B 已执行录音文件 → 英文 → 中文 → 时间轴/检查点保存及按时长回放测试。

69 词样本的重复英译中耗时约为 1.8B 0.86 秒、7B 3.57 秒；26.11 秒合成音频的 turbo + 1.8B 处理约 3.37 秒，计入缓存后的资源加载约 5.03 秒。turbo 本轮首次资源加载约 114 秒。首次加载、样本缓存和音频切句都影响体验，不能只凭推理吞吐做选型。

实际发现 1.8B 可能把“至少提前14天”译成“14天以内”，7B 仍可能把“收到申请”改成“提出申请”。固定 15 秒音频窗口切断条件句，small.en 在边界补词，turbo 的碎片翻译也产生严重误解。下一项开发优先完成 VAD、重叠合并及稳定整句提交，再接入麦克风原型。

完整指标、原文/译文问题及复现入口见 [M0模型联调报告](M0模型联调报告.md)。新增 `scripts/m0-smoke.sh` 已整轮运行成功，11 项基础自动检查通过；这不等于课堂质量、长时实时或完整离线验收通过。

## M0 要做什么

直接按已确定功能编写可运行代码，用实际结果决定模型、处理方式和支持边界。实现代码可继续用于后续应用；只有质量、离线和持续运行结果合格，才算通过对应验证。

| 验证项 | 最小可运行链路 | 需要观察的结果 |
| --- | --- | --- |
| 文字 | 原文 → 本地模型 → 译文及耗时 | 数字、否定、条件、术语、上下文、冷/热启动速度 |
| 文档 | 文件 → 文字/结构 → 来源位置 → 选段翻译 | 正文完整性、表格关系、阅读顺序、遗漏和失败提示 |
| 语音 | 音频 → 英文 → 中文 → 时间轴 | 全流程耗时、英文/中文质量、修正成本、时间戳 |
| 实时字幕 | 持续麦克风采集 → 稳定英文 → 中文 | 真实课堂距离和噪声、字幕延迟、积压趋势、过载及中断 |
| 离线与恢复 | 固定资源 → 禁止后备下载 → 新输入 → 中断/重启 | 资源完整性、断网可用、缺失资源明确失败、结果不丢失不重复 |

M0 无需先做完整菜单栏、收藏管理、漂亮界面或通用资源下载器。首版全部功能仍保留，M0 用最小代码优先验证会影响后续设计的路径。

## 验证程序已完成

- Swift Package 及 `translator-m0` 命令行程序，使用本机 Swift 6.3.3 编译成功。
- 本地服务诊断、模型元数据检查、英中双向翻译调用、NDJSON 流式完成检查、术语/数字核对提示和耗时报告。
- PDF 文字层、Vision OCR、Vision 文档结构识别、DOCX/PPTX 结构提取入口；TXT/MD 和常见图片读取。
- WhisperKit 固定源码及严格本地分词器补丁，语音资源清单与 SHA-256 校验。
- 录音分窗口转写、可选中文翻译、按原始时长逐段输入文件的 replay 测试入口、部分结果保存。
- 11 项 Swift Testing 检查通过：回环地址限制、流式多字节响应、截断及服务错误、内容核对提示、XML 实体/深度、关系路径约束、XML 命名空间、资源缺失、分词器缺失/坏文件、Office 顺序及正文、TXT/PDF 来源定位。

依赖见 `Vendor/README.md`，当前只有约 1 MB 的所需源码，不包含模型权重。使用 Swift 5 语言模式保持上游兼容，未将它表述为严格 Swift 6 并发验收。

## 尚未验证或尚未实现

1. 文字模型在真实学习生活材料上的质量与稳定性。HY-MT2 双向推理已运行，短样本已发现严重条件误译，默认模型仍待选定。
2. Whisper 在真实课堂录音中的质量。两套 Core ML 模型已能加载并处理合成英语，跨窗口分句问题待修复；合成音频不能代表口音、噪声和距离。
3. 完整断网后的新材料推理，以及整个运行过程的网络请求审计。
4. 麦克风实时字幕。当前 replay 只模拟录音文件随时间到达，用来测吞吐；独立约 15 秒窗口可能在边界漏词或重复，尚未完成 VAD、重叠合并、稳定文本提交及实时 UI。
5. 真实课程文档、Office 图片 OCR、完整列表编号/表格语义、文档段落翻译串联和双语导出。
6. 60–90 分钟持续运行、暂停/退出恢复、字幕导出和完整任务状态机。当前 `.partial.json` 只保存已完成内容，尚不支持自动续跑。
