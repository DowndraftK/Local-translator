# 个人自用正式初版使用与恢复说明

更新：2026-10-02。0.2.9，固定新任务7B-v2配置。实际交付构建号、包路径和逐项验收结论见[实体故障与恢复验收记录](0.2.9实体故障与恢复验收记录.md)。本文编写时第三轮验收仍在进行，不将候选包当作已完成交付。

## 打开与本机资源

本版面向当前Apple Silicon Mac，最低macOS 26，采用本机临时签名。双击交付目录中的“本地翻译器.app”。ZIP是同一应用的压缩副本，不包含模型，也不是跨机器的独立安装发行版。

请保留本项目目录、本机Ollama中的HY-MT2模型，以及以下语音资源。移动或清理它们会影响识别；应用不会自动下载、换模型或关闭校验。

- Python环境：`artifacts/whisperlivekit-gpu-review-20260915/venv`。
- 固定识别源码及指纹：`artifacts/whisperlivekit-speech-repair-20261001-final/source`、同目录`patched-source.json`。
- 语音权重：`models/whisper-mps-experiment/large-v3-turbo`；基线清单：`experiments/whisperlivekit/mps-model-manifest.json`。
- 翻译模型：`hy-mt2:7b-q8`与`hy-mt2:1.8b-q8`。旧任务可能仍需1.8B。

“本机资源”可以检查Ollama、选择语音资源目录。服务未运行时主动点击“启动本地服务”；应用不会停止原本已运行的Ollama。

## 文字翻译与找回

1. 在“文字翻译”粘贴全文，选择方向和模型，点击“开始翻译”。新任务默认7B、`hy-mt2-faithful-v2`，自动安全分段、串行请求。
2. 完整原文、分段计划、实际请求配置、成功译文和状态自动保存。注意窗口底部“已自动保存”“有未落盘内容”或“保存失败”，不要只看翻译进度。
3. 停止、退出或异常结束后，点击“打开已保存任务”。打开只读取，不自动推理。主动点击“继续未完成 / 重试失败”才处理待处理、失败和中断段；成功段保留。
4. 当前请求中尚未提交的半段可以安全重做。失败段每任务累计最多三次尝试，不无限自动重试。
5. “重新开始”建立新任务并保留原版。旧任务继续自己的模型、提示、参数和分段；新默认不会自动重译旧任务。
6. “导出双语TXT”保留全部原文及真实完成、失败、待处理和中断状态。未成功译出的段不会假装已有译文；输入草稿也可导出。

## PDF、TXT与OCR

“文档与图片”选择“PDF / TXT整篇”。PDF默认文字层，不自动OCR；可翻译全部页或连续物理页范围，每轮最多200页，源文件最多256MB。TXT支持UTF-8及BOM。文档保留经过大小、SHA-256核验的受管理源副本，原文件不改写；原路径移动后仍可读取已保存任务和回查源副本。

扫描件须主动选择“显式整页OCR（需核对）”。逐页核对后编辑原文，点击“保存校正”才形成有效修订；未应用的编辑草稿另行保存。原始OCR证据、有效校正、核对标记和来源清单均保留。导出使用有效修订，不将未应用草稿混入译文来源。

打开后主动继续缺失页或未完成段，保留已提取页、校正和成功译文。“从头重新翻译”另建结果归属；重新核对已翻译原文也先保留旧任务。源副本不匹配时会报错，保留可读原文/译文及导出，禁止继续提取另一份来源。

复杂双栏、表格、公式、图片文字和Office整篇不在本次完整支持范围。OCR取得文字、人工核对与翻译完成均不能证明内容准确完整。

## 麦克风、暂停与停止

麦克风由你主动点击“开始麦克风录音”，并允许本应用权限。准备模型期间的话不会录入；应等待界面确实显示录音状态。可勾选“仅录音，稍后识别”先保存声音，之后主动“继续识别”。没有系统声音采集或说话人分离。

“暂停录音”会排空已接收缓冲并保留样本位置。暂停期间的墙钟时间不写成假声音。继续前检查设备和权限，再主动点击“继续录音”。设备变化或休眠会暂停；唤醒不自动开麦克风。权限被关闭时，按系统设置→隐私与安全性→麦克风重新允许本应用；macOS可能要求退出或重新打开应用。

点击“停止并保存”后等待尾部和工作进程结束。不要把旧快照中的录音状态当作进程仍运行的证明。保存失败或工作进程异常退出会停止本次输入并显示提示，可能只能读取最后有效保存位置。

## 录音中断后的恢复、回放与导出

在“录音翻译”打开整个已保存任务目录。打开不自动识别或补译。识别未完成时主动“继续识别”，先核验音频和固定资源，再从安全检查点重做未确认尾部；没有检查点则从头处理，并将旧尾部保存在恢复历史。它处理已保存音频，不重新开启已结束任务的麦克风。

英文先入SQLite，中文由独立队列生成。“继续补译 / 重试失败”仅补未完成中文，保留成功结果。修改英文产生新修订，旧中文失效；迟到请求不能覆盖新修订或新配置。“录后重新校对”生成独立新任务，保留原音频与字幕版本。

点击片段时间可回放保存的音频。TXT/SRT/VTT使用同一有效媒体时间，保留全部段落及未翻译标记。字幕时间是估计，异常位置需要听原音频核对；处理完成不代表识别或翻译质量已通过。

## 保存失败与最后有效边界

空间不足、写入权限或文件损坏时先保留当前窗口和错误提示，尽可能把内存原文/译文导出到有空间的其他位置。不要反复继续推理或覆盖原任务。清理仅由自己确认可删除的文件，释放空间后主动重试保存/继续；正常退出会等待保存，失败时可选择返回应用导出。

文字和OCR草稿有350毫秒防抖，另有后台排队、编码和磁盘耗时；持续输入会重置计时。这不是绝对最大未保存时间。异常退出只保证已经成功持久化的内容，当前半段、刚生成而尚未提交的结果、未保存输入或校正草稿可能重做或丢失。录音管道、采样转换及文件同步也有未写入缓冲，不承诺断电或崩溃零损失。各次实测的最后有效快照/样本边界见验收记录，不能外推成所有场景保证。

未知配置、模型digest变化或未知格式会明确拒绝继续，保留可读内容和导出。最新文字快照损坏时可读取经过验证的上一有效版本并警告；损坏文件保留，不能静默覆盖，应导出后新建任务。不要手工改checksum、模型指纹或成功结果binding绕过检查。

## 保存目录与备份

- 文字/文档：`~/Library/Application Support/LocalTranslator/TextDocuments/<UUID>/`，包含`current.json`、`previous.json`及`source-<SHA256>.pdf/.txt`。schema1 envelope保存Codable JSON的base64 payload和SHA-256。
- 录音：`~/Library/Application Support/LocalTranslator/Recordings/<UUID>/`，包含SQLite、音频、运行配置、事件及恢复历史；数据库schema3。

先停止任务并正常退出，再复制整个任务目录备份；运行中只复制SQLite主文件可能漏掉WAL事务。源副本、模型和运行资源也有各自依赖。保存格式未加密，没有跨机同步、完整资料库管理或自动修复界面。原子替换及文件同步不能替代独立备份。

## 已接受的翻译与验证限制

新HY任务固定温度0.1、top_p0.6、top_k20、repeat_penalty1.0、seed42、8192上下文/4096输出、keep_alive5m；仅向支持thinking的模型发送think:false。阅读分段`natural-language-utf8-v1`，字幕`subtitle-confirmed-v1`，上下文`none-v1`。1.8B是手动速度选项；旧recipe v1及成功译文保持原归属。

第二轮有限质量改善已交付，但D02的by/之前边界、D20的before/by、H09的中位数/平均值，以及少量否定范围问题仍存在。D02事实说明勘误以0.2.8指标的review_errata为准。重要日期、金额、条件、否定、频率与统计概念须对照原文，不把数字一致、模型正常结束或本轮故障通过当作语义正确。没有用户人工质量验收，也没有证明Q8量化是错误主因。

真实课堂、多人/噪声、课堂端到端延迟、复杂文档全面覆盖和完整断网/外连审计未完成。本轮不重新做模型选型、参数搜索、提示深调或长课堂质量专项；其他暂缓功能不因个人初版交付自动恢复。设备条件导致的实体未验证项单独列入验收记录，由用户决定是否接受，不能当作通过。
