# 原生流式字幕、录后校对与 TED 实测

日期：2026-09-17。交付版本：0.2.1，构建 4。此报告对应已实现的录音闭环，完整首版仍未全部验收。

## 结论

用户指定的 **MLX GPU 编码 → PyTorch/MPS GPU 解码 → SimulStreaming** 已接入原生应用，并与本地 HY-MT2 翻译、任务保存、回放、纠错和导出连通。实际权重设备为 `mps:0` / FP32，MLX 使用 GPU，自动 CPU fallback 关闭。

11 分钟真人 TED 暴露了短合成样本没能暴露的问题：流式处理有明显漏词。第一次完整双语运行得到 147 段，中文全部生成，但英文对照官方稿的词错误率为 **12.62%**。相同音频、相同权重的录后完整 MLX 识别约 **18.75 秒**，词错误率 **1.85%**，删除错误从 174 个词降到 3 个词。

进一步将流式历史文字上下文限制为 128 个 token 后，同段 TED 词错误率降为 **4.92%**，队列峰值由 **21.76 秒降为 5.92 秒**，收尾由 **8.96 秒降为 0.71 秒**。本版采用这组默认值，仍不把单段测试推广为所有课堂的效果。

本版同时增加可选的“录后重新校对”：在新的关联任务中重识别并翻译，保留原始字幕。它改善录后阅读，不意味着流式漏词问题已经解决，也不能用录后吞吐推断实时字幕延迟。

## 真人材料与评分方法

材料为 Celeste Headlee 的 TED 演讲 [10 ways to have a better conversation](https://www.ted.com/talks/celeste_headlee_10_ways_to_have_a_better_conversation)，使用页面指向的官方视频和页面内官方英文 transcript。转换后的音频长 **680.2286 秒**，共 **10,883,657 个 16 kHz 单声道样本**。参考稿开头对应媒体约 4.14 秒处，不能把媒体和网页展示时长差异全部当成片头偏移。

视频 SHA-256：`08dc9199379f231adec584c1a180c643e269616f3097d922f7a441a50e324d17`。来源、链接和完整指纹保存在本机 `artifacts/real-speech-20260916/fixture-manifest.json`。原视频和完整稿只留在被 Git 忽略的本地测试目录，未收入应用包或版本化报告。

词错误率（WER）按官方稿 1,950 词计算，使用编辑距离统计插入、删除、替换。大小写和标点被归一化，弯引号统一；括号中的观众反应移除。数字与英文拼写、缩写展开、连写/分写仍计入错误，所以 1.85% 不全是意义错误，也不等于“98.15% 中文准确率”。评分工具为 [summarize_ted.py](../experiments/streaming-translator/summarize_ted.py)。

BBC Learning English 下载尝试遇到 TLS/连接失败，**本轮没有 BBC 实测结果**。TED 适合作为自然英语演讲基准，但单一演讲、较清晰的近讲录音不能代表课堂距离、多人或噪声条件。

## 已完成的基线

### 26 秒合成双语回归

6 个英文句子及 6 个中文结果全部保存，417,809 个样本全部送入；ASR 处理时间 27.03 秒，输入结束后约 0.92 秒提交完成。首个确认英文 token 约 1.35 秒。样本中的退款句没有被中途拆开，但翻译仍弱化了“only if”且没有准确保留“received”，因此中文质量没有通过完整验收。

### 11 分钟 TED：默认 0.5 秒合并

| 指标 | 结果 |
| --- | ---: |
| 英文 / 中文段数 | 147 / 147 |
| 英文词错误率 | 12.62%（246 / 1,950） |
| 插入 / 删除 / 替换 | 43 / 174 / 29 |
| ASR 从开始输入到结束 | 689.19 秒 |
| 输入结束后收尾 | 8.96 秒 |
| 累计 ASR 调用 / 次数 | 673.67 秒 / 501 次 |
| 待处理音频峰值 | 21.76 秒 |
| 英文提交到中文完成：中位 / P95 | 0.536 / 1.206 秒 |
| 模型估计句末到中文完成：中位 / P95 | 11.94 / 23.68 秒 |

最后一行使用模型估计的句末时间，不是人工标注的语音结束；第一轮时钟元数据比实际回放时钟约早 0.5 秒，数值应作近似。后续已修正时钟保存位置。期间还运行过应用编译，所以这不是严格隔离的硬件性能基准。

漏词包含开头 6 个词、一个约 41 词的连续片段，以及后段重复替代原文等；不能归因于标点评分差异。日志显示首次 VAD 将前 5 秒作为静音跳过，而离线识别的开头讲话约从 4.14 秒开始，提供了语音起点被裁掉的线索。上下文接近解码长度上限和上游防重复重置也需要继续独立排查，尚未确认各自贡献。

### 中断的 1 秒合并试验

此任务曾接收全部音频并保存 146 段中文，但最后快照停在 `finishing_asr`。9 月 17 日检查时工作进程锁已释放且无完成记录。它属于**未完成试验**，没有被补记为成功，也不参与完整 WER 或延迟比较。已保存英文和译文仍可打开；补译不会把未结束的 ASR 冒充完整识别。

### 完整 128-token 历史上下文对照

保持相同模型、MPS FP32、0.5 秒输入/合并、同一原音频，显式设置 `--max-context-tokens 128`。它限制已移出音频窗口的历史文字长度，为当前解码保留空间；并未换模型或关闭 VAD。

| 指标 | 原始上下文 | 128 token |
| --- | ---: | ---: |
| 英文 / 中文段数 | 147 / 147 | 163 / 163 |
| 词错误率 | 12.62% | 4.92% |
| 插入 / 删除 / 替换 | 43 / 174 / 29 | 20 / 51 / 25 |
| 输入结束后收尾 | 8.96 秒 | 0.71 秒 |
| 待处理音频峰值 | 21.76 秒 | 5.92 秒 |
| 估计句末到中文：中位 / P95 | 11.94 / 23.68 秒 | 3.21 / 7.28 秒 |
| 英文提交到中文：中位 / P95 | 0.536 / 1.206 秒 | 0.429 / 1.155 秒 |

第二轮全部样本接收、EOF 暂存为空、163 段翻译全部完成。ASR 总耗时 680.94 秒，累计调用 646.89 秒 / 872 次。首个确认 token 为 6.67 秒，第一段中文为 23.02 秒：首次翻译包含约 14.74 秒的服务/模型启动等待，不能隐去这项等待只报告后续中位数。

这一轮也同时进行了原生应用构建，且两轮不在同一时刻运行，因而不能把变化全部归因于硬件加速比。它足以支持把 128 token 作为当前自用候选默认配置，尚不足以证明可靠的长课堂性能。当前仍有 51 个删除错误，必须保留录后核对。

## 验证与限制

### 原生应用内录后校对与导出

通过真实应用点击“录后重新校对”，从首轮 TED 保存的录音创建了独立任务：152 段英文和 152 段中文全部完成。MLX 识别约 **22.88 秒**，包括校验、复制录音、识别和中文补齐的工作进程总操作耗时约 **57.58 秒**。英文词错误率再次为 **1.85%**（16 个插入、3 个删除、17 个替换）。18.75 秒是前述单独诊断的识别时间，不能替代这一实际应用耗时。

已在应用中验证原始字幕保留、校对完成计数、片段回放/暂停，以及 SRT 导出。应用导出的 SRT 与任务内生成的字幕逐字节相同；SRT 和 WebVTT 均由 PyAV/libav 成功解析为 152 个字幕包。默认导出名重复扩展名的问题已在最终构建中修复。实际点击导出的验证来自前一个构建；最终构建的菜单自动化出现控件 ID 失效，未把后缀修复后的保存框复测计为通过。最终构建已重新打开保存任务，并通过运行代码一致性和签名验证。

麦克风共用的 stdin 输入使用 26.113 秒文件模拟：以不规则小包按原速送入，最终短包为 4,964 字节；归档的 417,809 个 PCM 样本与输入逐字节相同，6 段英文全部保存，EOF 后无残留前缀。此验证不启用实体麦克风。

不含完整稿的 [汇总数据](../experiments/streaming-translator/ted-results.json) 已纳入项目；[汇总工具](../experiments/streaming-translator/summarize_delivery.py) 可在原始本地证据保留时重新生成。

- Python 24 项检查通过：分句、小数/缩写、真实重复、事务回滚、旧请求隔离、源修订、恢复、不重做已成功翻译、导出、校对版本隔离与录音校验。
- 恢复试验使用本地模拟服务和测试专用子进程，在第二个翻译请求中断后重新启动；没有终止用户共用服务。
- Swift 12 项测试通过，新增采样转换测试覆盖 44.1 / 48 kHz 两个用例，连续不规则输入在 EOF 后得到精确时长，修复了滤波尾部多出样本的问题。
- Release 打包、签名严格验证、包内命令行入口均通过。已打开真正的 `.app`，载入 147 段 TED 双语任务并检查窗口布局和完成计数。
