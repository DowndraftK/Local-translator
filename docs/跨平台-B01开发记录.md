## 2. 本批实现

主路线为**Qt6/PySide6-Essentials + Python共享worker + 明确平台适配**。有限比较Tauri2的界面/sidecar/工具链、许可、体积和运行成本；未安装Rust/Tauri或制造两套业务规则。旧SwiftUI及生产`Sources`、`runtime`、`scripts`保持；原型独立在`prototype/b01`。

实际实现：

- 一个共享Qt Widgets窗口，连接/能力页及文字、文档、录音、资源四个占位页。后批能力明确“尚未实现”。
- 协议1.0匿名stdin/stdout JSONL，64KiB帧上限，session/request/operation/lease UUID及连续sequence；旧session、重复/乱序、错误lease被拒绝。
- 真实请求循环内发ready，父进程30秒未确认则失败。exit0在缺ready或缺shutdown确认时仍是失败。
- 有限无模型probe、单活动操作、进度、租约、安全取消、完整已确认前缀/摘要和尾部确认；取消晚于完成时幂等处理。
- 正常关闭先排空本批worker，5秒保护只针对父进程持有的QProcess；停止和重新连接使用新的session及PID。
- 能力/诊断明确Python隔离状态、平台/进程身份、无模型/无生产任务/未验GPU。没有监听端口、Ollama调用或生产数据库入口。
- 原生Windows只读开工核对脚本，实际根目录与本地源码commit必传；读取同仓库/分支/任务资料、CPU/RAM/磁盘/各卷余量/GPU/独立显存/驱动及工具，缺口显式记录。脚本尚未在Windows执行。

本批没有迁移全部文字业务，没有实现CUDA/OCR/麦克风/安装器，没有下载模型、运行推理质量对照或公开上传二进制。probe的合成步骤不能充当译文、数据库保存或录音安全落盘证据。
