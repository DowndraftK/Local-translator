# ADR-B01：共享桌面界面与本地worker主路线

决策日期：2026-10-04。下文保留B01决策与当时证据；2026-10-05用户已授权接续B02及Windows测试，当前状态见[B02记录](跨平台-B02开发记录.md)、[协议1.1](跨平台-B02本地worker协议.md)和[共同功能矩阵](跨平台-共同功能矩阵.md)。B01历史“Windows未连接/未下载”不作为当前状态。目标仍0.2.11开发预览。

## 决策

选择 **Qt6 / PySide6-Essentials 6.10.2 + Python共享worker + 明确平台适配**。B01用Qt Widgets、QProcess和标准库worker验证；不引入QtWebEngine或PySide6-Addons。现有SwiftUI App继续作为可用Mac入口、旧数据核对和迁移基线，原型独立在`prototype/b01`，候选在新`dist/B01-*`位置，不改原App打包脚本/版本或生产运行层。

共享任务规则的长期落点为独立Python核心，界面只表达操作/状态，不维护第二份业务规则。B01仅建立边界、协议和冻结夹具，**尚未迁移**Swift文字分段/任务状态机/保存恢复，也不复制Swift实现后称为共享核心。B02在既有Swift行为夹具约束下逐步集中文字规则；原Swift业务保留直到新候选达到实际共同门槛。

## 有限候选比较

初始固定6.8.3在Mac build48/49实际桌面辅助功能访问后退出发生SIGSEGV，报告栈落在QAccessibleCache删除QTableWidget等对象。改变Qt/Python对象销毁顺序仍失败，因此本批改为**固定6.10.2**，创建新的受控开发venv，保留旧环境和失败候选；这是一项真实兼容缺陷驱动的换版，实际结果见开发记录。两平台ABI3 wheel来源/hash均重新登记，Mac重新验证受影响协议/Qt客户端和原生桌面退出。Windows仅取得metadata，未安装或运行；本批未对后续CUDA/PDF依赖锁版本。

依据已读取的[Qt for Python许可说明](https://doc.qt.io/qtforpython-6/licenses.html)、[Tauri官方开发前提](https://v2.tauri.app/start/prerequisites/)与[Tauri2.8.5 MIT文本](https://github.com/tauri-apps/tauri/blob/tauri-v2.8.5/LICENSE_MIT)。未选Tauri仅做资料和接入成本比较，没有下载/执行Tauri或Rust。实际固定依赖在[lock](../prototype/b01/dependencies.lock.json)，对应PyPI metadata与wheel的HTTPS/hash实查，不用候选名代替实际身份。

## 契约与旧身份

协议1.0与TextDocuments schema1/SQLite schema3/recipe版本分开。父子匿名管道、30秒ready保护、session/request/operation/lease身份、有限progress与cancel/尾部/退出均已实施。业务能力由worker明确报告，UI占位不能升格为已实现。

实读代码确认Swift binding使用Foundation漂亮排序JSON，Python字幕使用紧凑排序UTF-8 JSON；两者字段名及浮点字节表示不同。共享协议不将二者hash互换；冻结的原recipe字节/dialect/binding和成功结果保持，旧Swiftv1仍省略contextVersion。自编CRLF/中文/路径/重复句夹具经现有生产编码器生成，不使用唯一任务内容。B01只读校验，不宣称新核心已能互写所有任务。

资源定位未来依据内容hash和明确平台资源身份，保留旧runtime.json绝对路径证据；Windows根目录必须实机确认。任务显式传输一致副本，SQLite关闭/一致备份和WAL完整规则继承，Mac/Windows串行修改，不并发写同一DB。

## 运行/分发边界与后续前置

B01 Mac App为临时签名的项目开发候选，固定本批venv路径；尚非可脱离开发环境的B09运行包。实查6.8.3和6.10.2的两份Mac wheel均无LICENSE/NOTICE/COPYING文件，不能把pip自己的许可证计作Qt许可闭环。已从Qt官方qtbase v6.10.2取得LGPL3/GPL3/GPL2参考文本并留存来源/hash，但实际模块/插件/第三方清单、对应源码和重链接仍有缺口。App本身不捆绑模型/任务。Qt开发环境体积、旧App和1.18GB语音运行软件是不同对象，不合并称为正式安装量。最终动态库/插件闭包、签名、离线替换库和对应源码义务在B09/B10以实际包核查；公开上传未授权也未执行。

当前Windows关机，项目根/本地同仓库及分支/最新资料、CPU/RAM/盘/GPU专用显存/驱动/工具/外部资源/Qt加载与GUI均未取得本轮证据。Win11x64及8845H/32GB/两块1TB/RTX4070Laptop来自用户说明，连接历史不能替代实读。待开机登录后先完成B01Windows补验；本次交付B01独立成果后停止，不自动实施B02—B12。

## B02接续决策（2026-10-05）

主路线保持。共享Python核心已接双向文字、配置/binding、分段装箱、调度、schema1保存恢复和完整TXT；Qt只表达操作/结果，Swift旧入口及全部生产运行层保持。Mac适配只提供NaturalLanguage/Character边界；Windows适配只提供Qt6.10.2句子/字素边界，UTF-16到UTF-8转换明确，身份`qt6102-unicode-utf8-v1`。旧已有计划不重排，跨适配器旧无计划草稿拒绝重新规划。没有第二份完整业务规则。

Windows项目根经用户确认，空本地Git仓库由完整本地bundle接续同一`codex/cross-platform-b01`分支；随后源码增量串行交接，保留两端状态，不查询远端SHA或自动合main。Win11x64/8845H/32GB/两盘/RTX4070Laptop实读，专用显存8188MiB、驱动595.79；连接与硬件不当作GUI/CUDA语音/安装器验收。

固定Windows开发解释器为官方python-build-standalone CPython3.12.14/build20260825 x64，来源/hash/21980002字节已登记于[依赖锁](../prototype/b01/dependencies.lock.json)。Qt两份固定wheel实际下载校验合计75768542字节；原生安装目录按文件字节计：基座63483892、Qt venv220142739，未去重，也不是B09正式安装量。venv启动器的额外子进程已由真实进程句柄适配消除；共享协议/业务规则不为Windows复制。

实际Windows两份wheel各含`LicenseRef-Qt-Commercial.txt`，metadata仍列LGPL/GPL选择；这些文件不代表完整LGPL、Qt模块/插件/第三方、源码及重链接义务已闭环。Mac wheel历史缺许可文本证据保留。Qt/CPython继续只用于受控个人开发预览；B09独立运行包、B10实际资产分发条件和公开二进制授权仍待各批处理。

文字验证使用现有固定Ollama0.35.0。Windows官方ZIP来源/hash/签名实际核对后只在受控目录解压，模型是用户授权复制的两份已校验HY-MT2 Q8，位于下载目录的独立资源根，不进入源码Git。它们不构成B05 CUDA ASR或B11产品联网安装验收。各候选启动/实际GUI、有限真实流程、体积/内存口径和未验证项以B02记录/指标为准；交付B02后停止，B03—B12未启动。
